## 2. Service + location pages (144)

Every page also draws one box for `slc-services-section` (4:3, "Technician with inspection equipment at a residential property, no identifiable address or people"), the image in the right-hand column of the services section (`components/templates/ServiceLocationPageTemplate.tsx`). It is one shared slot, so it is appended to every row below and is not repeated in the slot registries.

Each registers six slots through `pageImageSlots()` (hero, cta, four problem cards). Only the four problem-card slots draw a box.

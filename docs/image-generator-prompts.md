# Image generator prompts

Render and illustration files only. 12 shots. Source: [image-shot-list.md](image-shot-list.md). Real-photo files are on the [photographer shot sheet](photographer-shot-sheet.md).

These prompts ask for a photorealistic render with natural light, realistic materials and a neutral documentary look, to match the existing owner-approved renders on the site. They are renders of generic scenes, not photos of a real customer job, and must never be presented as one. Nothing here should show inspection footage, pipe interiors, a crew, a vehicle or signage. Keep every file free of text, so alt text carries the meaning.

## Settings for every prompt

- Aspect ratio 4:3, output at least 1448 x 1086 px, then export as WebP.
- Generate four candidates per prompt and keep the one with the least clutter.
- Reject any result with text, numbers, a vehicle, a person, a readable sign, a house number, a pipe interior or any visible damage, and re-run.
- Use the same style words across all twelve so the set looks like one family, and compare each result with an existing owner-approved render before accepting it.

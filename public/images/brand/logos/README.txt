FILE SELECTION
Use PNG when transparency and broad compatibility are priorities.
Use WebP for optimized website delivery.
Use JPG only for the supplied fixed-background placements.
Use favicon.ico for legacy browser compatibility and the supplied PNG icons for modern devices.

IMPORTANT SOURCE NOTE
The supplied logo is a 930 x 189 raster WebP. The package preserves that artwork and provides
production-ready raster derivatives. A true vector master (SVG/EPS/PDF paths) would require the
original vector file or a separate vector-redrawing project.

# Who We Serve hub image slots

Save real photography at these paths (WebP, about 150 KB or less; hero tiles roughly 900px
wide, card images roughly 1200px wide, CTA roughly 1672px wide).
`data/business/audience-hub-images.ts` uses the file at build time when it exists and falls
back to an existing owner-supplied scene until then. No code change is needed to swap.

| Slot | Path (under this folder) | Subject |
|---|---|---|
| Hero tile 1 | `hero/the-sewer-pros-hub-camera-monitor.webp` | Sewer camera monitor showing live pipe footage |
| Hero tile 2 | `hero/the-sewer-pros-hub-technician-review.webp` | Technician reviewing footage with camera equipment |
| Hero tile 3 | `hero/the-sewer-pros-hub-customer-consultation.webp` | Technician explaining findings to a homeowner or buyer |
| Hero tile 4 | `hero/the-sewer-pros-hub-field-work.webp` | Equipment or service vehicle at a property, no market-naming signage |
| Home buyers card | `cards/the-sewer-pros-home-buyers.webp` | Buyer and technician reviewing findings |
| Home sellers card | `cards/the-sewer-pros-home-sellers.webp` | Documented findings for a property being listed |
| Real estate agents card | `cards/the-sewer-pros-real-estate-agents.webp` | Findings shared in a transaction context |
| Home inspectors card | `cards/the-sewer-pros-home-inspectors.webp` | Camera work alongside a home inspection |
| Property managers card | `cards/the-sewer-pros-property-managers.webp` | Diagnosis at a multi-unit or managed property |
| HOA communities card | `cards/the-sewer-pros-hoa-communities.webp` | Shared sewer infrastructure, evidence in hand |
| Final CTA | `cta/the-sewer-pros-hub-cta.webp` | Service scene, no single market shown as the business's place |

Do not use skyline stock photos, generic handshakes, a storefront, an address, a branch, or
any image that implies repair or replacement work.
